# Airline Management System (Linux-Based)

A terminal-based Airline Management System developed using **Bash scripting** on Linux (Ubuntu/WSL). This project demonstrates practical use of Linux commands, file handling, and shell scripting concepts through a menu-driven airline booking application.

---

## 📌 Features

* Add new flights with seat capacity
* View all available flights
* Book tickets with passenger details
* Prevent overbooking using seat tracking
* View booking records
* Cancel bookings using CNIC/Passport
* Search flights by source and destination

---

## 🛠️ Technologies Used

* Bash Shell Scripting
* Ubuntu Linux (WSL)
* Linux Commands (`grep`, `sed`, `awk`, `cat`, `chmod`)
* Text files for data storage

---

## 📂 Project Structure

```
Airline_Management_System/
│
├── airline.sh      # Main bash script
├── flights.txt     # Stores flight details
├── bookings.txt    # Stores booking details
└── README.md
```

---

## ▶️ How to Run

1. Open Ubuntu (WSL or Linux terminal)
2. Clone the repository or download the files
3. Navigate to the project directory
4. Make the script executable:

```bash
chmod +x airline.sh
```

5. Run the system:

```bash
./airline.sh
```
